# Техническое задание на разработку игры «Змейка» (Snake Game)

**Версия документа:** 1.0  
**Дата:** 20 февраля 2026 г.  
**Статус:** Утверждено

---

## 1. Введение

### 1.1. Назначение документа
Данный документ описывает функциональные и технические требования к игре «Змейка» для веб-браузеров. Игра должна корректно работать на ПК и мобильных устройствах.

### 1.2. Область применения
ТЗ предназначено для разработки, тестирования и приёмки игры.

### 1.3. Глоссарий
| Термин | Определение |
|--------|-------------|
| **Кубик (cell)** | Базовая единица игрового поля (20×20 px) |
| **Змейка** | Управляемый игроком объект, состоящий из кубиков |
| **Еда** | Бонусный объект, появляющийся на поле |
| **Game Over** | Состояние проигрыша |

---

## 2. Общее описание

### 2.1. Цель игры
Управлять змейкой, собирать еду, избегать столкновений со стенами и собственным хвостом.

### 2.2. Платформы
- **ПК:** Управление стрелками клавиатуры
- **Смартфоны/Планшеты:** Сенсорное управление (свайпы)

### 2.3. Требования к адаптивности

#### 2.3.1. Динамический размер кубика
Размер базовой единицы (кубика) **не фиксирован** и зависит от:
- Разрешения экрана устройства
- Размера окна браузера
- Типа устройства (ПК / планшет / смартфон)

| Устройство | Рекомендуемый размер кубика |
|------------|-----------------------------|
| ПК (≥1024 px) | 25–30 px |
| Планшет (600–1023 px) | 20–25 px |
| Смартфон (<600 px) | 15–20 px |

#### 2.3.2. Общие требования
- Игра должна корректно отображаться на экранах любого размера
- Игровое поле должно масштабироваться, сохраняя пропорции
- Размеры поля должны быть **кратны размеру кубика**
- Все элементы интерфейса должны быть доступны и читаемы
- Кнопки управления должны быть удобного размера (≥44×44 px для touch-устройств)

## 4. Технические требования

### 4.1. Архитектура
- **Формат:** Single HTML file (HTML + CSS + JS)
- **Тесты:** Jest + jsdom
- **Хранение:** localStorage для рекордов

### 4.2. Требования к коду
| Требование | Описание |
|------------|----------|
| T1 | Размер кубика вычисляется динамически на основе ширины экрана |
| T2 | Корректная работа keyboard events (preventDefault) |
| T3 | Сброс всех параметров при рестарте (скорость, счёт, змейка) |
| T4 | Анимация Game Over (fade-in overlay) |
| T5 | Модальное окно с полупрозрачным фоном |
| T6 | Количество ячеек поля: 20×20 (независимо от размера кубика) |
| T7 | Минимальный размер поля: 300×300 px |
| T8 | Максимальный размер поля: 600×600 px |

### 4.3. Структура данных

#### 4.3.1. Объект состояния игры
```javascript
state = {
  canvas: HTMLCanvasElement,
  ctx: CanvasRenderingContext2D,
  box: number,           // размер кубика (вычисляется: 15–30 px)
  gridSize: 20,          // количество ячеек (20×20)
  snake: Array<{x, y}>,  // сегменты змейки
  food: {x, y},          // позиция еды
  direction: string,     // текущее направление
  nextDirection: string, // следующее направление
  score: number,         // текущий счёт
  highScore: number,     // рекорд (из localStorage)
  gameRunning: boolean,
  isPaused: boolean,
  isGameOver: boolean,   // состояние проигрыша
  intervalId: number,
  speed: number,         // текущая задержка (мс)
  baseSpeed: 200,        // начальная задержка
  minSpeed: 50,          // минимальная задержка
  speedDecrement: 10,    // уменьшение за каждый кубик
  locale: 'ru' | 'en'
}
```

#### 4.3.2. Локализация
```javascript
SETTINGS = {
  locale: 'ru',
  texts: {
    ru: { /* тексты на русском */ },
    en: { /* тексты на английском */ }
  }
}
```

## 6. Исправляемые баги (из текущей версии)

| ID | Описание бага | Решение |
|----|---------------|---------|
| B1 | Стрелки клавиатуры не работают | Добавить `preventDefault()` и корректную обработку `keydown` |
| B2 | При рестарте скорость не сбрасывается | Сбрасывать `speed` до `baseSpeed` (200 мс) в `restartGame()` |
| B3 | Скорость не повышается с каждым кубиком | Уменьшать задержку на `speedDecrement` (10 мс) при поедании еды |
| B4 | Размеры поля не кратны кубику | Вычислять `box` динамически: `Math.floor(size / gridSize)` |
| B5 | Фиксированный размер кубика (20 px) | Сделать адаптивным: 15–30 px в зависимости от экрана |
