# 🐍 Snake Game

Классическая игра «Змейка» с современным интерфейсом, адаптивным дизайном, уровнями сложности и поддержкой мобильных устройств.

## 🎮 Особенности

- **3 уровня сложности** — Лёгкий, Средний, Сложный
- **Адаптивный дизайн** — работает на ПК, планшетах и смартфонах
- **Двуязычный интерфейс** — русский и английский
- **Сенсорное управление** — свайпы, тапы и on-screen кнопки
- **Таблица рекордов Топ-10** — лучшие результаты со всеми уровнями
- **Справка** — модальное окно с правилами и управлением
- **Тапы по экрану** — определение направления относительно головы змейки
- **Ускорение игры** — скорость растёт с каждым съеденным кубиком
- **Стабильный UI** — фиксированные размеры, нет масштабирования

## 🎯 Управление

### ПК
- **Стрелки** ↑ ↓ ← → — движение змейки
- **Тап** по игровому полю — направление от головы змейки

### Смартфоны/Планшеты
- **Свайпы** по игровому полю — движение в направлении свайпа
- **Тапы** по игровому полю — направление относительно головы змейки
  - Тап справа от головы → вправо
  - Тап слева от головы → влево
  - Тап выше головы → вверх
  - Тап ниже головы → вниз
- **On-screen кнопки** (включаются кнопкой "Touch")

## 🎮 Кнопки управления

| Кнопка | Описание |
|--------|----------|
| **Лёгкий/Средний/Сложный** | Выбор уровня сложности (перезапускает игру) |
| **Restart** | Начать игру заново |
| **Pause** | Пауза / Продолжить |
| **Рекорды** | Показать лучший счёт |
| **RU/EN** | Переключить язык |
| **Touch** | Вкл/Выкл сенсорные кнопки |

## 🏗️ Технические детали

### Уровни сложности

| Уровень | Нач. скорость | Мин. скорость | Уменьшение |
|---------|---------------|---------------|------------|
| **Лёгкий** | 300 мс | 100 мс | 5 мс |
| **Средний** | 200 мс | 50 мс | 10 мс |
| **Сложный** | 120 мс | 30 мс | 15 мс |

### Адаптивный размер кубика
| Устройство | Размер кубика |
|------------|---------------|
| ПК (≥1024 px) | 25–30 px |
| Планшет (600–1023 px) | 20–25 px |
| Смартфон (<600 px) | 15–20 px |

### Хранение данных
- Рекорды сохраняются в `localStorage`
- Таблица Топ-10 лучших результатов
- Ключи: `snakeScores_easy`, `snakeScores_medium`, `snakeScores_hard`
- Отдельные рекорды для каждого уровня сложности
- Сортировка по счёту (убывание)

## 🎯 Правила игры

1. Выберите уровень сложности (по умолчанию — Средний)
2. Управляйте змейкой с помощью стрелок, свайпов или тапов
3. Собирайте красные кубики (еду)
4. За каждый съеденный кубик:
   - Змейка растёт на 1 сегмент
   - Скорость игры увеличивается
   - Вы получаете 1 очко
5. Избегайте столкновений:
   - Со стенами
   - С собственным хвостом
6. При проигрыше можно начать заново

### 💡 Советы по управлению

**Тапы по игровому полю:**
- Тап **справа** от головы змейки → вправо
- Тап **слева** от головы змейки → влево
- Тап **выше** головы змейки → вверх
- Тап **ниже** головы змейки → вниз

Система автоматически фильтрует невозможные развороты на 180°.
