# 🐍 Snake Game

Классическая игра «Змейка» с современным интерфейсом, адаптивным дизайном и поддержкой мобильных устройств.

## 🎮 Особенности

- **Адаптивный дизайн** — работает на ПК, планшетах и смартфонах
- **Двуязычный интерфейс** — русский и английский
- **Сенсорное управление** — свайпы и on-screen кнопки
- **Сохранение рекорда** — лучший счёт сохраняется в localStorage
- **Ускорение игры** — скорость растёт с каждым съеденным кубиком

## 🚀 Быстрый старт

### Вариант 1: Открыть в браузере
```bash
# Просто откройте файл index.html в любом браузере
xdg-open index.html          # Linux
open index.html              # macOS
start index.html             # Windows
```

### Вариант 2: Локальный сервер
```bash
# Установите зависимости
npm install

# Запустите сервер (требуется serve)
npx serve .

# Или используйте Python
python -m http.server 8000
```

## 🎯 Управление

### ПК
- **Стрелки** ↑ ↓ ← → — движение змейки

### Смартфоны/Планшеты
- **Свайпы** по игровому полю
- **Тапы** по сторонам экрана (определяет направление от центра)
- **On-screen кнопки** (включаются кнопкой "Touch")

## 🎮 Кнопки управления

| Кнопка | Описание |
|--------|----------|
| **Restart** | Начать игру заново |
| **Pause** | Пауза / Продолжить |
| **Рекорды** | Показать лучший счёт |
| **RU/EN** | Переключить язык |
| **Touch** | Вкл/Выкл сенсорные кнопки |

## 🏗️ Технические детали

### Адаптивный размер кубика
| Устройство | Размер кубика |
|------------|---------------|
| ПК (≥1024 px) | 25–30 px |
| Планшет (600–1023 px) | 20–25 px |
| Смартфон (<600 px) | 15–20 px |

### Скорость игры
- Начальная: 200 мс
- Уменьшение: 10 мс за каждый кубик
- Минимальная: 50 мс

### Хранение данных
- Рекорд сохраняется в `localStorage`
- Ключ: `snakeHighScore`

## 🎯 Правила игры

1. Управляйте змейкой с помощью стрелок или свайпов
2. Собирайте красные кубики (еду)
3. За каждый съеденный кубик:
   - Змейка растёт на 1 сегмент
   - Скорость игры увеличивается
   - Вы получаете 1 очко
4. Избегайте столкновений:
   - Со стенами
   - С собственным хвостом
5. При проигрыше можно начать заново
